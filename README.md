## 🚀 Quickstart & Installation

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn package manager

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tarunjit45/Pujo_media.git
   cd Pujo_media
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch development server:**
   ```bash
   npm run dev
   ```
